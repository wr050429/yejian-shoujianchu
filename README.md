# 夜间收件处

一个很短的值夜班网页小游戏。你是雾汀市立文书收件处的夜间值班员：每班只来几件无人认领、无法归类或被退回的东西，你读、写一两句批注，然后决定「归档」还是「暂缓结案」。

- 在线地址：https://wr050429.github.io/yejian-shoujianchu/
- 首版是一次短值班：三班，分别 3 / 4 / 3 件。故事在班次之间慢慢积下来。

## 怎么玩

1. 开场读完收件处的职责，点「开始值班」。
2. 每班先看到收件盘，点一件拆开：图版、物理细节、可见文本。图版上的字迹以「可见文本」为准。
3. 在物件页写批注，选「归档」或「暂缓结案」。本班结束前都能改，再点一次可撤回。
4. 什么时候点「结束本班」由你定；有没拆开的件会轻声提醒一下，但照样可以交班。交班后可以在下一班里翻看前几班的卷宗（只读）。
5. 三班值完是值班日志：只列你自己的批注和处理。「重新值班」会清掉记录。

没有分数、没有正确率、没有标准答案，这里也不提供任何「该怎么归档」的说明。

## 记录留在哪里

批注和归档只存在你自己浏览器的 localStorage 里（刷新不会丢，换浏览器或清缓存就没了）。不会上传到仓库、服务器或任何统计服务。页面没有后端、没有统计脚本、不加载外部字体。

## 文件

- `index.html` + `app.js` + `assets/`：构建产物，由 GitHub Pages 直接提供。图版以 base64 文本打包存放在 `assets/*.json`（缩略图、桌面、每班一包），页面加载时在浏览器里解码。
- `src/app.tsx`（界面）、`src/main.tsx`、`src/content.json`（值班员可见的文案）。
- 重新构建：`npm i && npx esbuild src/main.tsx --bundle --minify --jsx=automatic --outfile=app.js`
